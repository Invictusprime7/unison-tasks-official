# PrismaHero design reference

User example received 2026-09-17. Original: ../quarantine/user-prisma-2026-09-17/PrismaHero.tsx.txt. Local executable: hero:prisma-cinematic.

Use for immersive editorial and cinematic home pages with strong brand imagery and a short headline. Combine oversized word-reveal typography, a rounded media canvas, a legibility scrim and asymmetric supporting copy. Keep the CTA prominent and navigation canonical. On small screens stack supporting copy; respect reduced motion. Prefer simpler heroes for dense informational content.

The local implementation uses image props and CSS reveals. Video autoplay, external demo assets, duplicated navigation and placeholder links from the reference are not portable defaults. Attachment licensing was not supplied.
